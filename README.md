C++ Personal Expense Tracker

About

Personal Expense Tracker is a beginner-friendly C++ project that records expense names and amounts and calculates total spending.

Features

- Enter the number of expenses
- Add expense names and amounts
- Calculate total expenses
- Display the expense summary

Technology Used

- C++

Concepts Learned

- Variables and data types
- User input and output
- For loops
- Arithmetic operations
- Strings

How It Works

The program asks the user how many expenses they want to enter. It then accepts each expense name and amount and calculates the total spending.
